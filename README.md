## “双ISP”这个词，商家之间至少有三种解释

第一种是宣传口径：IP 段同时挂靠两家美国本土宽带运营商，在风控数据库里被归到住宅或 ISP 类别，而不是 hosting。多数卖家的页面停在这一层。

第二种更接近可操作的定义：同一个 IP 在两个 ISP 名下都有注册记录，套餐本身仍然只分配 1 个 IPv4，需要多 IP 得单独加购。这个说法最能解释“为什么叫双”却“只给一个”。

第三种是误读：一台机器接两条 ISP 线路，一条主用一条备用。这是把线路冗余和 IP 归属属性混成一件事，跟风控识别没有关系。

RakSmart 的官方表述只讲到 IP 归属方与线路所属主体均为 ISP 运营商，区别于传统 IDC 机房托管 IP，但没有展开“双”具体指两家运营商还是双重归属。也就是说，行业里连这个词都还没统一。

所以下单前值得发一句工单问客服：这个 IP 的 ASN 是多少，在 ipinfo 里 usage type 显示什么，是不是同时存在两个 ISP 的注册记录。能报出具体 ASN 的商家，比页面只写“双ISP住宅”的靠谱得多。

## 线路和 IP 属性是两条腿，别混着选

9929（AS9929，联通精品网）回程最稳，带宽上限低，LisaHost 这条线上限基本在 100Mbps。跑 ChatGPT、Claude 这类不吃带宽的固定出口最合适。

4837（AS4837）能拉到千兆，晚高峰比 9929 略有波动，适合要跑量的账号运营。

NTT 和 GTT 是美西骨干线路，卖点是 IP 段新、库存轮换快，追 IP 新鲜度的场景优先。

国际带宽和 Cogent 直连把成本压在线路上，IP 纯净度是唯一卖点，国内访问要自备中转，新手直接上会很难受。

只需要国内访问快、不跑社媒账号的，选 CN2 GIA 或 9929 优化线路就行，为 ISP 属性加的钱用不上。

## 几个高频问题

**双ISP 会给两个 IP 吗？** 不会。套餐默认 1 个 IPv4，需要更多得单独加购，RakSmart 这类按个或按段卖的机型可以直接配。

**买了双ISP 还是被限流怎么办？** 先排查同 IP 多账号、登录设备指纹、操作行为。这些都正常的话，大概率是 IP 段被打标了，换段试，NTT 换 GTT、一期换二期都有意义。

**月付还是年付？** 不确定业务能不能跑起来就月付，48 小时退款窗口够你验证 IP 属性。确定长期用再转年付，但先核对年付版的流量额度有没有缩水。

**能换 IP 吗？** 各家政策不同，年付用户通常有免费更换次数，月付可能要付费，下单前问清楚比事后扯皮省事。
